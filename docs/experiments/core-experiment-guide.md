# 核心篇实验指导

## 实验清单

| 实验 | 工具 | 主要产物 |
|---|---|---|
| TCP拥塞控制分析 | Wireshark、绘图工具 | cwnd/重传分析表 |
| 路由算法模拟 | Python或手工迭代表 | 两类算法收敛记录 |
| HTTP协议抓包分析 | 浏览器、Wireshark | 请求响应与缓存字段截图 |
| DNS解析过程 | nslookup/dig、Wireshark | 递归与迭代查询链 |
| TCP三次握手与四次挥手 | Wireshark | 标志位、序号和状态表 |
| 子网划分计算 | 计算表 | 网络地址、广播地址、主机范围 |
| NAT工作原理 | Packet Tracer或路由器仿真 | 内外地址映射表 |
| Socket编程实践 | Python | TCP/UDP客户端和服务器 |

## 通用实验流程

1. 阅读对应知识点和案例背景，明确输入条件与预期现象。
2. 按 `backend/data/cases.json` 中的步骤执行并保存原始证据。
3. 将抓包、命令输出、拓扑或程序运行结果与协议字段对应。
4. 回答案例分析问题，说明现象产生的原因，而不是只粘贴截图。
5. 通过知识图谱节点进入关联试题，完成实验后的自测。

## 验收要求

- 抓包实验需提交过滤表达式、关键报文编号和字段解释。
- 计算实验需写出公式、单位和结果校验。
- 仿真实验需记录拓扑、参数、故障注入和收敛过程。
- 编程实验需包含运行方法、正常输入、边界输入和异常处理结果。
