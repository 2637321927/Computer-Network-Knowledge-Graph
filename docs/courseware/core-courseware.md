# 核心篇课程讲义

## 第5章 网络层

### 学习目标

- 理解IP提供的无连接、尽最大努力交付服务。
- 掌握IPv4地址、子网掩码、CIDR、最长前缀匹配和IPv6。
- 理解ARP、ICMP、NAT的工作过程。
- 区分路由与转发，比较距离向量和链路状态算法。

### 学习主线

```text
逻辑寻址 -> 子网与CIDR -> IP数据报 -> ARP/ICMP/NAT
        -> 转发表与最长前缀匹配 -> RIP/OSPF/BGP
```

学习本章时应能独立完成子网划分、路由表匹配和Traceroute过程分析，并能解释IPv4与IPv6的主要差异。

## 第6章 传输层

### 学习目标

- 理解端口、套接字、复用与分用。
- 比较TCP与UDP的服务模型和适用场景。
- 掌握TCP三次握手、四次挥手、序号确认和超时重传。
- 区分流量控制和拥塞控制，理解滑动窗口、慢开始、拥塞避免、快重传和快恢复。

### 学习主线

```text
进程通信 -> 端口与Socket -> UDP
                     -> TCP连接管理 -> 可靠传输
                     -> 流量控制 -> 拥塞控制
```

本章重点是把协议字段与状态变化对应起来，并能根据ACK、RTT、rwnd和cwnd分析连接行为。

## 第7章 应用层

### 学习目标

- 理解客户-服务器和P2P体系结构。
- 掌握DNS递归/迭代查询、缓存和资源记录。
- 分析HTTP请求响应、持续连接、Cookie、缓存、HTTPS和HTTP/2、HTTP/3。
- 理解FTP、SMTP、MIME、POP3、IMAP、DHCP与WebSocket。
- 使用Socket API实现基本TCP和UDP程序。

### 学习主线

```text
应用体系结构 -> DNS与名称解析 -> HTTP/HTTPS与Web
             -> FTP与电子邮件 -> Socket编程
```

学习结束后应能从浏览器输入URL开始，串联DNS、IP、TCP或QUIC、TLS和HTTP的完整通信过程。
